# Secure Full-Stack Todo Application

A modern, full-stack Todo application built with **React (TypeScript & Vite)**, **Node.js/Express**, and secured with **JWT Authentication**.

---

## Features
- **Secure Authentication:** User registration and login powered by JSON Web Tokens (JWT) and bcrypt.
- **Context-Based State:** Global state management using React Context (`AuthContext`) with persistent storage (`localStorage`).
- **Theme Management:** Seamless dark and light mode toggle with automatic root HTML class synchronization.
- **Protected Routing:** Guarded routes that prevent unauthorized access to private views.
- **Modern UI:** Clean, responsive design built with React functional components and styled icons (`lucide-react`).

---

## Tech Stack

### Frontend
- React (TypeScript)
- Vite
- React Router v6
- Axios
- Lucide React (Icons)

### Backend
- Node.js & Express
- JWT (JSON Web Tokens)
- Mysql / Database of choice
